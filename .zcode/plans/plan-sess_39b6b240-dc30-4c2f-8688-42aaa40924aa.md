# 编辑器体验优化 — 第一批实施计划(feature/editor-optimize)

目标:补齐与 VSCode 差距最大的"导航与发现性"缺口 + 三个低成本的编辑器核心修正。阶段 3/4(零配置 LSP、Problems 面板、调试器等)列为后续,不在本批。

## 阶段 1:导航与发现性(本批主体)

### 1.1 命令注册中心
- 新建 `lib/core/services/commands/command_registry.dart`:统一的 CommandDefinition(id、标题(i18n)、快捷键、回调、可见性),启动时登记现有硬编码动作(save/saveAs/new/open/upload/run/find/replace/comment/goToDef/rename/format 等,来源 `lib/features/edit_core/main.dart:89-150` 与 `lib/pages/editor/main.dart`)。
- 快捷键解析改走注册中心,行为不变(为阶段 4 的自定义快捷键铺路)。

### 1.2 Quick Open(Ctrl+P)
- 模糊匹配器(子序列匹配 + 连续/词首加分,纯 Dart 可单测)。
- 列出来源:工作区文件树(`local_tree`) + 已打开标签页;键盘上下选择、Enter 打开(复用现有 openFile 流程)。

### 1.3 命令面板(Ctrl+Shift+P)
- 复用 Quick Open 的浮层组件,数据源换成 CommandRegistry;展示快捷键提示;支持插件菜单命令(`menu_resolver`)后续接入。
- 浮层复用 code_forge 已有的 line-anchored popup 模式或居中 dialog,风格对齐 M3。

### 1.4 全局搜索/替换面板
- 底部 ConsoleWorkspace 新增 Search tab(与 REPL/Log/Terminal 并列)。
- 遍历工作区文本文件(排除 .git/build/node_modules/二进制),流式搜索避免 UI 卡顿;支持大小写/整词/正则开关。
- 结果分组按文件,点击跳转到 文件+offset(复用 `lsp_location_dialog` 的跳转逻辑)。
- 替换:确认后逐文件应用(复用 `lsp_text_edits.dart` 风格的偏移映射,或简单 replaceAll + 脏标记)。

### 1.5 外部文件变更检测
- `Directory.watch(recursive: true)` 监听工作区(Windows 支持良好),debounce 后对已打开标签比对 mtime/内容 hash。
- 未修改的标签静默重载;已修改的弹提示条(重新加载/保留我的版本)。板载(board)文件不监听。

### 1.6 最近文件
- `persistence_manager` 增加 recentFiles 列表(上限 ~20,去重,按最近打开排序)。
- Welcome 页(`lib/pages/editor/welcome.dart`)展示最近文件,点击打开;Ctrl+R 风格的最近列表入口放在 Quick Open 里(前缀 `@` 或空查询时显示)。

## 阶段 2:编辑器核心快赢(本批一并做)

### 2.1 按语言的注释切换
- `line_comment.dart` 泛化:接受行注释符参数(`#`、`//`、`--`);从 `editor_language.dart` 的语法映射表取当前文件注释符;Ctrl+/ 行为对 C/JS/Lua 正确。保持纯函数 + 单测。

### 2.2 Ctrl+G 跳转行
- 已有 SDK 命令 `sdk.editor.go_to_line`(`lib/core/sdk/api/editor.dart:27`),接一个行号输入浮层 + Ctrl+G 快捷键,注册进命令面板。

### 2.3 编码检测(中文用户痛点)
- 打开文件改为读 bytes:BOM 检测(UTF-8/UTF-16LE/BE)→ 严格 UTF-8 校验 → GBK 回退;状态栏显示编码,点击可切换重载/转码保存。
- 保存按选定编码写出;脏状态基线同步更新(`tabbed_view_controller_provider.dart` 的 text-vs-baseline 逻辑保持不变,基线存解码后文本即可)。

## 明确不做(本批,列为后续阶段)
- snippet 展开、minimap、分屏、sticky scroll(编辑器内核工作量大,单独排期)
- 零配置 LSP 安装引导、Problems 面板、本地 Python 运行、DAP 调试器
- `code_area.dart` 拆分、code_forge.dll 出库、AXTree 修复

## 验证
- 每项配单测(模糊匹配器、注释切换、编码检测、命令注册中心均为纯逻辑);`flutter analyze --no-fatal-infos lib test` + `flutter test`。
- 手工验证清单:Ctrl+P/Ctrl+Shift+P/Ctrl+G 全键盘可达;全局搜索大仓库不卡 UI;外部修改后提示条两种选择都正确;GBK 文件往返不乱码;C 文件 Ctrl+/ 生效。

## 预期效果
补齐导航/发现性短板(评分表中最弱两项之一),配合后续零配置 LSP,整体体验从 7 分迈向 8 分。
